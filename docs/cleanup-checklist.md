## 종료 순서 예시

1. 리전 **ap-northeast-2** 및 다른 리전의 실습 관련 리소스도 확인
2. EC2 종료(단순 Stop이 아니라 Terminate)와 EBS 볼륨/스냅샷 분리 잔존 확인
3. 사용한 EIP 해제, NAT Gateway/ALB/RDS 등이 있다면 삭제
4. IGW 분리 후 삭제; 서브넷/사용자 지정 라우팅/보안 그룹 등 종속성 확인 후 VPC 삭제
5. Billing/Cost Explorer에서 잔여 과금 항목 추적(비용 표시 지연 가능)

**주의:** 다른 프로젝트에서 사용하는 공유 리소스는 삭제하지 마세요. 키 페어, IAM 정책/사용자 등 실습 전용 접근 자격도 필요에 따라 정리하세요.
